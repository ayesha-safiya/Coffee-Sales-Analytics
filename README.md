# ☕ Coffee Sales Analytics Dashboard

## Project Overview

An interactive Power BI dashboard analyzing 4K+ coffee sales transactions to uncover revenue trends, customer behavior, and product performance. The dashboard uses KPI cards, time-based analysis, and dynamic filters to deliver actionable business insights and support data-driven decision-making.

## Key Features

- Interactive analysis of 4K+ coffee sales transactions
- KPI cards for key sales and performance metrics
- Revenue trend analysis over time
- Customer behavior analysis
- Product performance insights
- Dynamic filters and slicers for interactive exploration
- Visualizations designed to support data-driven decision-making

## Tools and Technologies Used

- **Power BI** – Dashboard development and interactive data visualization
- **Microsoft Excel** – Data preparation and storage

## Dataset

**Dataset File:** `Coffee_sales.xlsx`

## How to Use

1. Download or clone this repository.
2. Open `coffee sales dashboard.pbix` using Power BI Desktop.
3. Ensure `Coffee_sales.xlsx` is available in the `dataset` folder.
4. Update the data source path if required.
5. Refresh the data and explore the dashboard using the available filters and visualizations.
